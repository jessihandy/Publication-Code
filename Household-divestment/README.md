# Handgun divestment and adult cohabitant's suicide risk

The code for the original construction of the LongSHOT cohort are not publicly available, nor are the underlying data. Code specific to this analysis are included for posterity but not executable in the absence of full data access. Provided code includes files relevant for constructing the divestment cohort and accompanying matches, data cleaning, and analytic code for the included survival analyses and bootstrapping.
